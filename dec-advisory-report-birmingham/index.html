01 · Scope and preparation

A companion to the operational rating

The advisory report is a separate document from the DEC itself. It identifies opportunities to improve energy performance; it does not record completed upgrades or guarantee a reduction in bills. If you need both documents, include that in the enquiry so the scope can be agreed together.

02 · Scope and preparation

Start with the building and its actual operation

Supply the address, floor area, building use, available energy records and any existing DEC or advisory report. Explain changes in occupancy, opening hours or the areas included. The information needed for the certificate and report should be confirmed before work is arranged.

03 · Scope and preparation

Turn the recommendations into decisions

An advisory report can help organise further investigation and improvement work. Costs, technical feasibility and building constraints still need consideration before a recommendation becomes a project. A later EPC or a building-services design is a separate instruction.

Before you enquire

DEC Advisory Reports: useful answers

Is this the same as a DEC?

No. The DEC is the operational energy rating; the advisory report provides associated recommendations. We can review an enquiry for either or both.

Do all commercial properties need one?

No. DEC requirements concern qualifying public buildings. Private commercial premises should not be assumed to need a DEC simply because members of the public visit.

Can an old report be reused?

Send the existing report and details of the current building. Its applicability and validity need checking rather than assuming it still covers the instruction.
